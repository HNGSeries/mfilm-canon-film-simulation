# แผนงาน M-Film

ทำทีละข้อ เสร็จครบแล้วค่อยรวมเป็น PR เดียว (ต่อจาก #5 ไฟล์ 6D ที่ไม่มีห้องมืด)

## 1. รูปตัวอย่างฟิล์มบนชั้นวาง สำหรับกล้องทุกรุ่น (เล็ก)
- ตอนนี้ `build_fork.sh` ทำ `ML/SAMPLES` ให้แค่ EOS M แต่ไฟล์ตัวอย่างเป็นภาพ 720×480 ที่ไม่ขึ้นกับรุ่นกล้อง ใช้ชุดเดียวกันได้ทุกรุ่น
- build ที่ไม่มีห้องมืด (`--no-darkroom`) จะดูตัวอย่างไม่ได้ เพราะตัวอ่านภาพ (`fos_print_load`) อยู่ใน `fos_dev.c`: ย้ายตัวอ่านไปไฟล์เล็กของมันเอง (ไม่กี่ KB) ทุก build จะได้มี

## 2. สำรวจหน่วยความจำของกล้องทุกรุ่น ✅ (ผลอยู่ใน `ml-dev/MEMORY.md`)
- กล้องที่ ML จองหน่วยความจำแบบตายตัว (100D, 70D, 550D, 600D, 1100D) ไฟล์ใหญ่เกินทุกตัว แม้ตัดห้องมืดออกแล้ว
  ตั้งสถานะ `memory` แล้ว ยังไม่ build และยังไม่ปล่อยจนกว่าจะแก้
- กล้องที่ ML ขยายพื้นที่ให้พอดีเอง (650D, 700D, 5D3, 60D, 500D, 50D, 5D2) ไม่มีเพดานตายตัว
  60D ผ่านแล้ว 650D/700D ใหญ่กว่าเพดานของ EOS M (727K) ต้องระวัง
- **ต่อไป:** ขอผู้ทดสอบส่งค่า Debug → *Free Memory* จาก ML ปกติ แล้วขยายพื้นที่จองให้แต่ละรุ่นแบบที่ทำกับ 6D (#8)
  เริ่มจาก 70D ที่หน่วยความจำเหมือน 6D

## 3. โหมด Basic / Realistic (ตั้งค่าใน System) ✅
- **Basic** (ค่าเริ่มต้น): ไม่ต้องกรอฟิล์ม ถ่ายครบม้วนแล้วม้วนจบเองและส่งเข้าห้องมืดได้เลย ถ้าจะจบกลางม้วนใช้ "Finish roll" แทน Rewind
- **Realistic**: เหมือนตอนนี้ ต้องกรอฟิล์มกลับก่อนถึงจะล้างได้
- ใน log ของม้วน (`ROLL_nnn.TXT`) Basic เขียนบรรทัดจบม้วนให้เอง Darkrooms บนคอมจึงอ่านได้เหมือนเดิม
- แก้ที่ `filmroll.c` (จบม้วน), `fos_pages.c` (หน้า Roll, ตั้งค่า), `fos_dark.c` (ม้วนที่จบแล้วล้างได้)

## 4. หน้าจอถ่ายรูปสำหรับ DSLR (ไม่มี LiveView) ✅ (รอคนทดสอบบน DSLR)
- DSLR ถ่ายผ่านช่องมอง จอหลังไม่ได้เป็น LiveView: วาดหน้าแบบ "ฝาบนของกล้องฟิล์ม" แทน
  ชัตเตอร์, ค่า f, ISO ของฟิล์ม, ฟิล์มที่ใส่, นับรูปที่เหลือ
- แทนหน้าข้อมูลของ Canon (กด INFO) และหายไปเองเมื่อเอาตาแนบช่องมอง (เซนเซอร์ดับจอ)
- ต้องมีคนทดสอบบน DSLR: ทำหลังจากเรื่อง 6D บูตได้แล้ว

## 5. รุ่น 0.2 ✅ (รอทดสอบบนกล้องจริง)
- **ขนาดรูป** Small / Medium / Large เลือกก่อนล้าง (`fos_dev.c`: รูปใหญ่รวมพิกเซลไปพร้อมรูปขนาดจอ แล้วเขียน JPEG ทีละ 16 แถว)
  และ **ซูม** ในหน้า Prints จากไฟล์ `Fnn.ZOM`
- **หน้าล้างแบบนิ่ง** ไม่มี animation วาดใหม่เฉพาะตอนมีอะไรเปลี่ยน, INFO หรี่ไฟจอ
- **แบตเตอรี่ทุกหน้า**, **ช่องมอง 4 แบบ**, **Date stamp**, **ชั้น RECENT**
- **Home / Settings ใหม่**: Home เหลือ 3-4 แถวตามสถานะของม้วน, Settings หน้าเดียว + Manual lens + Advanced
  ตัด Wind lever แบบ "Locks shutter" ออก
- **build เดียว**: film OS เป็นโมดูลบนทุกรุ่น (`build_fork.sh` ไม่ต้องใส่ `--module` แล้ว, `--built-in` คือแบบเดิม)

### เพิ่มก่อนปล่อย 0.2.0
- **ไม่มีสไลด์ซ้าย-ขวา** เข้า/ออกเมนูเปลี่ยนหน้าทันที (เดิม 340 ms ราว 15 เฟรมเต็มจอต่อครั้ง)
  เฟดระหว่างชั้นวาง ห้องมืด และ Prints เหลือ 320 ms (เดิม 520) ปิดได้ที่ Advanced > Page fade
  บัฟเฟอร์ของเฟด (345 KB) จองเมื่อมีเฟดครั้งแรกเท่านั้น
- **Support M·FILM** ย้ายมาอยู่หน้า Settings ใต้ About, หน้า About มีบรรทัด **M·FILM BY HNGSERIES**
- CineStill 400T: คำบรรยายใหม่ "Cine film, cool shadows, red halos"
- **ตัวเลขใน HUD / ฝาบนสว่างเมื่อหมุนปุ่ม** 2 วินาที (เดิมสว่างเฉพาะตอนกดชัตเตอร์ครึ่งทาง จึงเห็นค่าที่เปลี่ยนชัดก็ต่อเมื่อถ่าย, #23)
- **ถือจอไว้จนบันทึกรูปเสร็จ** บนการ์ดช้า (เดิมรอสูงสุด 4 วินาทีแล้วจอของ Canon โผล่, #17) สูงสุด 20 วินาที
  และ log บอกว่าจอของเราหายไปเพราะอะไร นานเท่าไร
- **กล้องที่มีปุ่มหมุนสองตัว** (50D, 60D, 70D, 5D Mark II, 5D Mark III, 6D): บนชั้นวาง ปุ่มหมุนบนเปลี่ยนชั้น
  ปุ่มหมุนหลังเลื่อนฟิล์ม (#17) กล้องที่มีปุ่มเดียวเหมือนเดิม
- **EOS M: Advanced > Hide Canon's graphics** (ค่าเริ่มต้นปิด) ถือจอของ Canon ไว้ใต้ HUD แบบเดียวกับ DSLR
  กราฟิกชดเชยแสงของ Canon จึงไม่ทะลุ HUD (#67) แลกกับกรอบโฟกัสของ Canon ที่หายไปด้วย ยังไม่ได้ลองบนกล้อง

### ที่ต้องวัดบนกล้องจริงก่อนปล่อย
- EOS M, 6D, 5D Mark III, 60D, 500D, 50D, 5D Mark II: โมดูลโหลดขึ้นไหม (เดิม build รวมไว้)
- เวลาต่อรูปของแต่ละขนาด (บรรทัด `dev: frame N: read ... big print ...` ใน `ML/FILMROLL.LOG`)
  ค่าเริ่มต้นที่ใช้ประมาณเวลา (15 / 39 / 66 วินาที) มาจากจำนวนคำสั่ง ARM ที่วัดด้วย qemu
  (0.90 / 2.3 / 4.0 พันล้านคำสั่งต่อรูปจาก RAW 18 MP) ไม่ใช่จากกล้อง
- หน่วยความจำ: รุ่นไหนล้าง Large ได้ รุ่นไหนถูกลดเป็น Medium / Small (`dev: no memory for a ... print`)
- หรี่ไฟจอ (INFO ตอนล้าง) และค่าความสว่างกลับมาเท่าเดิมไหม
- แบตเตอรี่: ไอคอน 3 ระดับบนรุ่นที่ไม่รายงานเปอร์เซ็นต์ตรงกับของ Canon ไหม

### ยังไม่ได้ทำ (ตั้งใจเว้นไว้)
- **Half-frame และ Push/Pull**: ต้องเปลี่ยน log ของม้วน (`ROLL_nnn.TXT`) ซึ่ง Darkrooms บนคอมอ่านอยู่ ต้องทำสองฝั่งพร้อมกัน
- **เมนูด่วนบน HUD (กด INFO ค้าง)**: ต้องดักปุ่ม INFO ใน LiveView ซึ่งเป็นปุ่มสลับหน้าจอของ Canon ทดสอบไม่ได้โดยไม่มีกล้อง
  ตอนนี้ใช้ INFO ที่ Home เข้า Settings แทน
- **ปิดจอจริงตอนล้าง**: film OS ปิดตัวเองเมื่อจอดับ จึงใช้การหรี่ไฟจอแทน

## 6. กล้องรุ่นใหม่และทางเลือกการล้าง (แผน ยังไม่เริ่ม)

ข้อมูลจากการสำรวจ ณ 10 พ.ย. 2026 ยังไม่ได้ลองบนกล้องจริง

### 6.1 Magic Lantern รุ่นใหม่
- **ใส่ในรายการ "Not yet"** ของ `README.md` / `README.th.md`: 1300D, M6 Mark II, XF605
  (มีใน `platform/` ของ magiclantern_simplified branch `dev` แต่ยังไม่มีใน README)
- **1300D** (DIGIC IV แบบเดียวกับ 1100D): ML รองรับครั้งแรกใน commit `142472e` (16 ก.ย. 2026, "experimental")
  global draw, โมดูล และค่า RAW มีแล้ว แต่ปิด `CONFIG_PROP_REQUEST_CHANGE` ไว้
  M-Film จึงตั้ง ISO และ Picture Style ตอนโหลดม้วนไม่ได้ (`filmroll/filmroll.c` ที่เรียก `prop_request_change_wait` และ `lens_set_rawiso`)
  รอ ML เปิดก่อน แล้ว build โดยใช้ 1100D เป็นต้นแบบ และตรวจหน่วยความจำตอนบูต (1100D ใช้ไป 493,056 จาก 524,032 ไบต์)
- **EOS R** (DIGIC 8): PR #281 ของ magiclantern_simplified ยังเป็น draft (แก้ ROM ผ่าน MMU remap, ถ่ายรูปได้, ตั้ง ISO / รูรับแสงได้)
  ส่วนที่พร้อม merge แยกไปเป็น PR #279 และ #280 รอให้เข้า `dev` ก่อนลอง build `R.180`

### 6.2 พอร์ตไป CHDK (PowerShot)
- CHDK stable 1.6.1 (rev 6355, 146 รุ่น), dev 1.7.0 (rev 6358, 154 รุ่น) จาก mighty-hoernsche.de
- **ทำก่อน**: G7 X (เซนเซอร์ 1"), S110 / S100 / S95 (เล็ก ราคาถูก), G16 / G15 (มีช่องมองภาพ) ทุกรุ่นมี build stable
- **รองลงมา**: G1 X, G5 X, G10–G12, G7 X II (BETA) และ EOS M3 / M10 (BETA, APS-C)
- **ไม่แนะนำ**: IXUS / ELPH และ A-series ส่วนใหญ่ไม่มีกลีบรูรับแสงจริง (ใช้แผ่น ND)
- ข้อมูลฟิล์มและ Darkrooms บนคอมใช้ต่อได้ (DNG) แต่ชั้นวางฟิล์ม, HUD และตัวนับเฟรมต้องเขียนใหม่
- ขั้นแรก: สคริปต์ Lua บน G7 X ที่วาดตัวนับเฟรมทับ LiveView ถ้าจอของ Canon วาดทับ (แบบ #64) ค่อยเปลี่ยนเป็น C module (`.flt`)

### 6.3 โหมด JPG (ทางเลือก, RAW ยังเป็นโหมดหลัก)
- ทำใน Darkrooms บนคอมก่อน (อ่าน JPG แล้วใช้ LUT ของฟิล์ม) ห้องมืดในกล้องทีหลัง เพราะต้องมีตัวถอดรหัส JPEG
- ข้อเสีย: 8 bit, ส่วนสว่างที่ขาวแล้วดึงกลับไม่ได้, ไวท์บาลานซ์และ Picture Style ของ Canon ติดมาแล้ว ต้องเตือนผู้ใช้
- ค่าที่แนะนำให้ตั้ง: Picture Style Neutral / Faithful, Contrast และ Saturation −2, Sharpness 0, WB Daylight, ชดเชยแสง −⅓ ถึง −⅔
- ทำให้ CHDK ใช้ได้ทุกรุ่น รวมรุ่นที่ไม่มี DNG
