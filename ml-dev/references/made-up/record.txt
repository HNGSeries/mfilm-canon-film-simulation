# The record of a paired shot: what was shot, how, and what each frame is.

# It is also the example of the format: a real record has the same lines.
#
# The format. One file per paired shot, references/<name>/record.txt. A line
# is "field: value". Everything after a "#" at the start of a line or after
# a space is a comment. Every field below has to be there with something
# written for it, except "made up" and "measured". How a paired shot is made
# is decided in #111.

# The frames, as #111 lists them, the same for every film stock:
#
#   frame N: what it shows | exposure | shutter speed | what it is used for
#
# Exposure is in stops from 0, where the Canon's spot meter reads the chart's
# mid-grey patch as normal; it is empty for a frame that has none. What a
# frame is used for is one of:
#
#   built from            the look is built from it
#   held back, decides    kept out of building the look; these decide whether the film stock is measured
#   held back, reported   kept out of building; measured and printed, decides nothing
#   drift                 the chart again at the end of the roll, to see that nothing changed
#   grain                 a grey card, for grain when it has a method
#   by eye                a scene, looked at
#   bare film             the lens cap on
#
# The first four show the chart and are the ones the measuring command reads.

# Where the chart is, in each set of pictures of these frames:
#
#   chart in SET: x,y x,y x,y x,y              in every frame of the set
#   chart in SET, frame N: x,y x,y x,y x,y     in that frame, where it differs
#
# The four points are the centres of the chart's four corner patches, in this
# order: dark skin, bluish green, black, white. That is top left, top right,
# bottom right, bottom left with the chart the right way up; a picture that
# is turned or mirrored needs nothing more than the points in that order.
# Each is a fraction of the picture, across from its left edge and then down
# from its top, so it holds for the picture at any size. The picture is the
# file as its pixels are stored: a turn that is only written in the file's
# tags is not applied.
#
# A set is a kind of picture of the frames: "canon" is the Canon frames as a
# developer prints them (the darkroom and Darkrooms print the whole frame, so
# they share it), "locked" the locked scan. An automatic scan, or a scan on
# another machine, is another set with its own lines.
